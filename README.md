# 🍔 Swiggy Sales Analysis Dashboard | Excel

An interactive **Swiggy Sales Analysis Dashboard** built using **Microsoft Excel** to analyze sales performance, customer ratings, orders, food types, locations, cities, restaurants, and time-based sales trends.

The dashboard transforms approximately **197K orders** into an interactive business intelligence report with KPIs, charts, slicers, and geographic analysis.

![Swiggy Sales Dashboard](dashboard.png)

---

## 📌 Project Overview

The objective of this project is to analyze Swiggy food-ordering data and identify important patterns in:

* Overall sales performance
* Order volume
* Customer ratings
* Average order value
* Monthly and weekly sales trends
* Food type performance
* State-wise sales
* City-wise sales
* Location-wise sales
* Restaurant performance
* Category performance

The dashboard allows users to interact with the data using **Excel slicers** for:

* Months
* Restaurants
* Categories

---

## 🎯 Business Objectives

The dashboard was created to answer key business questions such as:

1. What is the total sales generated?
2. How many orders were placed?
3. What is the average order value?
4. What is the average customer rating?
5. Which months generate the highest sales?
6. Which food type contributes more to sales?
7. Which states generate the highest sales?
8. Which cities are the top-performing markets?
9. Which locations generate the highest sales?
10. How does sales performance change over time?
11. Which categories and restaurants contribute most to sales?

## 📈 Dashboard Features

### 1. Monthly Sales Trend

A line chart shows sales performance across different months.

This helps identify:

* High-performing months
* Low-performing months
* Overall sales movement
* Seasonal patterns

---

### 2. Sales by Food Type

A doughnut chart compares sales between:

* Veg
* Non-Veg

This helps understand customer preferences and the contribution of different food types to total sales.

---

### 3. Sales by Day

A column chart analyzes sales performance by day of the week.

It helps identify which days generate higher order volumes and sales.

---

### 4. Location by Sales

The dashboard compares sales across different locations such as:

* Gomti Nagar
* Nerul
* Thane West
* Whitefield
* Yelahanka

This helps identify high-performing delivery locations.

---

### 5. City by Sales

The dashboard highlights major cities based on sales performance.

Top cities displayed include:

* Bengaluru
* Hyderabad
* Lucknow
* Mumbai
* New Delhi

---

### 6. State-wise Sales

A geographic map is used to visualize sales performance across Indian states.

This provides an easy way to identify strong and weak regional markets.

---

### 7. Weekly Sales Analysis

A weekly sales chart displays sales performance across multiple weeks.

This can be used to identify:

* Weekly fluctuations
* Sales peaks
* Low-performing weeks
* Overall sales consistency

---

### 8. Interactive Slicers

The dashboard contains interactive slicers that allow users to filter the entire dashboard by:

**Month → Restaurant → Category**

This makes the dashboard dynamic and useful for business analysis.

## 🧹 Data Analysis Process

The project followed a basic data analytics workflow:

### Step 1 — Data Collection

Imported the Swiggy order dataset into Microsoft Excel.

### Step 2 — Data Preparation

Reviewed and prepared fields such as:

* Order Date
* State
* City
* Restaurant
* Category
* Price
* Rating
* Rating Count

### Step 3 — Data Analysis

Used Excel aggregation and Pivot Tables to calculate:

* Total sales
* Total orders
* Average rating
* Average order value
* Sales by month
* Sales by city
* Sales by state
* Sales by food type
* Sales by location

### Step 4 — Visualization

Created:

* KPI cards
* Line charts
* Column charts
* Doughnut chart
* Bar charts
* Map visualization

### Step 5 — Dashboard Development

Combined all visualizations into a single interactive dashboard and added slicers for easy filtering.
